Послідовність команд для виконання Лабораторної роботи №2 (Синиця Назар
, 32-ІСТ):

1. Створення Dockerfile та docker-compose.yml у гілці main.
2. Перехід на гілку develop та злиття з main за допомогою git merge.
3. Запуск мультіконтейнерної архітектури (FastAPI + PostgreSQL) у фоновому режимі:
   docker compose up -d --build

4. Перевірка статусу запущених контейнерів:
   docker compose ps

5. Перевірка переліку встановлених бібліотек всередині контейнера:
   docker exec -it fastapi_web poetry show

6. Зупинка контейнерів після завершення роботи:
   docker compose down
